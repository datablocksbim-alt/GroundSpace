# GS-003 — Ground Space local chat prototype

GS-003 is a local browser interface over the existing Administrator queue and Ground Space bridge. It provides Chat, Agents, and Tasks views without Electron, Docker, a JavaScript build chain, or third-party Python packages.

## Start

From the repository root:

```powershell
.\tools\start_ground_space.ps1
```

The server binds only to `127.0.0.1:8765`, opens the local interface, and prints a one-session owner approval token. If `GROUND_SPACE_OWNER_TOKEN` is already set, that value is used instead. Private state is stored under `%LOCALAPPDATA%\DataBlocks\GroundSpace`, outside this repository.

Use the printed owner token when the approval dialog appears. It is retained only in browser `sessionStorage`, not conversation history or Git.

## Chat behavior

- Qwen supports `explanation`, `assessment`, and `code_proposal`. Conversation context is bounded to eight recent messages and 8,000 characters before being sent to the model.
- Administrator supports `help`, `list tasks`, and `status <task-id>`. These are read-only queue operations.
- Every request is created through `AdministratorAdapter.submit()` with pending approval.
- Authenticated approval calls `AdministratorAdapter.approve()`, then dispatches asynchronously through `OrchestratorAdapter.process()`.
- The browser polls the authoritative task record while inference runs, keeping the interface responsive.

## Security

- State-changing requests require an exact localhost `Origin`, JSON content type, a SameSite cookie, and matching custom CSRF header.
- Approval additionally requires the owner token using constant-time hash comparison.
- Static files are served from a fixed allowlist; chat cannot select files, paths, processes, or shell commands.
- Qwen remains tool-free and proposal-only. The Administrator console reads only Ground Space's private queue.
- Private conversations, queue records, approval audit data, and credentials are outside the public repository.
- No cloud fallback exists, and Pyrene P2.5 is outside every worker's authority.
