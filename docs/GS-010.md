# GS-010 — Coordinator-first group chat routing (implementation draft)

This change is intentionally stacked on the GS-008 draft branch. It **does not** deploy code on the owner's Windows laptop, merge into `main`, or enable project execution.

## First-pass behavior

- The named **Coordinator** is the default responder to ordinary group chat messages.
- `/goal ...` and `/milestone ...` notes route to Coordinator, preserving GS-008 note styling and history. For goals, Coordinator uses a local Ollama model to **propose** at most three task cards as chat text.
- The Coordinator is a Python routing/prompt layer, **not** a new paid model. It prefers an installed group member whose name begins with `ministral`, otherwise uses the group's first registered model. Responses show `Coordinator` as speaker and the underlying local model in the metadata.
- `@Qwen` routes to the group's Qwen 2.5 Coder model when present; otherwise a unique Qwen match. `@Granite` and exact `@model:tag` mentions route to that registered group member. Multiple explicit specialists are processed sequentially using the existing group GPU lock. Unavailable or ambiguous mentions return an error, rather than silently selecting a different model.
- `@ChatGPT` and `@Claude` reject requests while provider connections are disabled.
- Unaddressed group messages no longer prompt **every** local AI, avoiding cross-talk and unnecessary inference load.

## Approval and security boundaries

Chat prompts produce proposal-only tasks through the existing queue with `read` and `propose` permissions. The automatic approval on **chat inference requests** is **not** approval to execute proposed project work. Task-card parsing, durable proposal records, owner approval UI, dependency scheduling, file edits, and command execution are **not implemented** by GS-010. Do not equate completed model inference with a completed development task. No cloud calls or API charges are enabled.


Manual browser checks in a group containing a local Qwen model:

1. Ask `What is our next step?` — one **Coordinator** message should appear, not one from every group member.
2. Enter `/goal Finish Pyrene Codex tablet` — saved goal and one Coordinator planning reply with proposed, unapproved steps.
3. Enter `@Qwen Review the Codex architecture` — Qwen replies under its own name.
4. Enter `@Claude Hi` — validation error, no paid request.
5. Confirm that opening a project does not grant file access, and no proposed task can be dispatched from chat.
