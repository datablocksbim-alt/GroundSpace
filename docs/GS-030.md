# GS-030 — One menu for rename and remove

**Implementation candidate only.** The existing GS-029 production app has not been restarted, replaced or modified through GitHub. GS-030 is built on `feature/gs-029-project-folder-picker`.

## Compact design

The user requested **no separate Options screen**. Projects and their nested AI group chats each have the same tiny **···** control. Tap it to show **Rename** and **Remove project** (folder row) or **Rename** and **Delete chat** (chat row) directly in one small menu.

- **Rename** → a compact text field and Cancel / Save name. Project label changes never rename or modify its ASUS folder. Chat renames preserve ID, history, models and approval modes.
- **Remove project** → the existing confirmation, with linked group chats moved to *General · unassigned*; their conversations and approvals remain intact; actual ASUS files are untouched.
- **Delete chat** → explicit confirmation, then unregister the group from navigation, **not** erase the private conversation or audit ledger. This is a conservative non-destructive delete. Chat deletion is refused while any linked queued/active tasks, Codex jobs or Co-work runs remain, including old records outside the recent UI list.
- **Cancel** in either dialog makes no change.

The old intermediate `Options` dialog was removed. Menus have touch-friendly tap areas and fit in the iPhone-sized drawer, without another page or sidebar section. The private AI chat list remains unchanged; GS-030 specifically covers registered project/group chat entries shown in the screenshot.

## Safety

All modifications are protected by Ground Space's existing private owner access, same-site Origin check and CSRF control. Server validates names/IDs and confirms the current saved name before acting. No filesystem deletion or global auto-approval is introduced. Existing project, group and chat records are loaded without migration.

## Testing and isolated ASUS preview

GS-030 CI runs Windows and Ubuntu regressions, queue/approval safety tests, and Chromium iPhone-size / desktop click tests confirming menu content, cancel, persistence, and unchanged conversations. Chromium is not a physical iPhone Safari test.

For a **non-destructive preview** after CI passes, run on the ASUS in PowerShell:

```powershell
$ErrorActionPreference = "Stop"
$source = "D:\000_AI Project\GroundSpace-GS029-Preview"
$preview = "D:\000_AI Project\GroundSpace-GS030-Preview"
if (-not (Test-Path (Join-Path $source ".git"))) { throw "GS-029 worktree missing" }
if (Test-Path $preview) { throw "GS-030 preview already exists; do not overwrite it" }
git -C $source fetch origin "+refs/heads/feature/gs-030-chat-project-management:refs/remotes/origin/feature/gs-030-chat-project-management"
if ($LASTEXITCODE -ne 0) { throw "Fetch failed" }
git -C $source worktree add --detach $preview refs/remotes/origin/feature/gs-030-chat-project-management
if ($LASTEXITCODE -ne 0) { throw "GS-030 worktree creation failed" }
Set-Location $preview
.\tools\prepare_gs030_preview.ps1 -StartPreview
```

Open `http://127.0.0.1:8783` in a browser **on the ASUS** (through Google Remote Desktop if controlling from iPhone). This is loopback-only and uses private isolated state under `%LOCALAPPDATA%\DataBlocks\GroundSpace-GS030-Preview`. It intentionally does **not** include the live user's historical chats; the browser integration tests cover preservation of representative existing chats.

Do not point Tailscale to port 8783. Do not run the old GS-029 cutover helper to activate GS-030; it validates GS-029 release identity and is not compatible. A version-specific backed-up migration/cutover is a separate step following owner acceptance and completed CI.

No Windows reboot, Pyrene modification, public account mode change, or merge into `main` is part of this work.
