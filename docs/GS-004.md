# GS-004 — Copy responses and multi-model local AI

## What changed

- Every completed AI response now has **Copy response**. It copies the full raw answer, including multiline code and whitespace, not just the visible preview. The browser first uses the Clipboard API, with a standard selection-based fallback.
- In **Chat**, choose an **AI model** from registered local Ollama models, and a response profile: **Fast** (up to 256 tokens), **Balanced** (640 tokens), or **Detailed** (1,200 tokens). These are output/compute limits, not guaranteed output speeds or tokens-per-second targets.
- In **Agents → My local models**, add one or more models already installed in Ollama using the discovery dropdown, or remove them. Up to 12 models can be registered. Changes persist in private state at `%LOCALAPPDATA%\DataBlocks\GroundSpace\private\chat_models.json`, outside GitHub. Removing a model from Ground Space does **not** delete its Ollama files.
- The system stores the chosen model and profile on each task, routes to a separate model-specific worker, and shows the model and observed generation speed/duration when Ollama provides metrics.
- **ChatGPT/OpenAI** and **Claude** appear as *not connected*. No API adapters, credentials or paid usage are introduced. They cannot be chosen until actual provider authentication and connectors are implemented.

## Boundaries

The model list is server-owned, and add requests accept **only installed local Ollama models**, verified against `127.0.0.1:11434/api/tags`. Browser requests cannot select an unregistered model, override a worker, supply an endpoint, or grant permissions. Each local model is a tool-free, proposal-only chat worker. Previously unqualified models remain unqualified for autonomous gameplay writes or review approval; adding them for chat does not change that.

The Administrator is still read-only from chat. Existing local-only binding, Origin/CSRF protections, audit/queue records, task IDs and subprocess cancellation are retained. No Pyrene files are modified.

## Setup

From the Ground Space repo root in PowerShell:

```powershell
git pull origin main
.\tools\start_ground_space.ps1
```

Open `http://127.0.0.1:8765`. In **Agents**, add other installed Ollama models, such as `qwen3.5:4b` if present, then return to **Chat** and select one. Use **Detailed** for larger coding proposals and **Fast** for short replies.

## Validation

```powershell
& 'D:\000_AI Project\AI Agents Datablocks\runtime\python\python.exe' -m unittest discover -v
```

Check that copy works for multiline code, model selection routes to the chosen worker, model registrations survive restart, invalid/uninstalled models are rejected, and all previous GS-001–003 tests pass. Inspect task result fields for the actual `tokens_per_second` metric when supported by Ollama.

These additions do not guarantee that an installed model will have adequate memory/performance on every laptop.
